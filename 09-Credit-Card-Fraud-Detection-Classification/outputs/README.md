# 🖥️ Execution Outputs — Credit Card Fraud Detection

## 📌 Overview

This directory contains screenshots of the execution outputs generated during the development and execution of the **Credit Card Fraud Detection using Machine Learning Classification** project.

These screenshots provide visual evidence of the project's workflow, including dataset inspection, exploratory data analysis, preprocessing, model comparison, hyperparameter tuning, model evaluation, and final execution results.

## 📂 Files Description

### 1. `execution_dataset_eda.png`

Shows dataset information and Exploratory Data Analysis (EDA) output, including dataset dimensions, data types, missing values, duplicate records, statistical summaries, and transaction class distribution.

### 2. `execution_preprocessing.png`

Shows the execution output for feature preparation, target separation, stratified training and testing data splitting, and preprocessing pipeline creation.

### 3. `execution_model_comparison.png`

Displays the cross-validation results used to compare Machine Learning models based on AUPRC, Precision, Recall, and F1-Score.

### 4. `execution_tuning_cv.png`

Shows Logistic Regression hyperparameter tuning results and cross-validation performance, including the best parameters and mean AUPRC.

### 5. `execution_threshold_evaluation.png`

Documents the classification threshold selection and final evaluation metrics, including Precision, Recall, F1-Score, and AUPRC.

### 6. `execution_error_analysis.png`

Shows error analysis results, including false positives, false negatives, and the top features identified during Logistic Regression model interpretation. It also documents the model-saving output when included in the screenshot.

### 7. `execution_final_summary.png`

Displays the final project summary, selected model, evaluation metrics, saved results, and successful completion message.

- Make the implementation easier to understand and verify.
