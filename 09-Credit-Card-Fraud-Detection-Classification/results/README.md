# 📊 Results — Credit Card Fraud Detection

## 📌 Overview

This directory contains the evaluation results, model comparison reports, and hyperparameter tuning results generated by the **Credit Card Fraud Detection using Machine Learning Classification** project.

These files help analyze model performance and evaluate how effectively different Machine Learning algorithms identify fraudulent credit card transactions.

## 📂 Files Description

### 1. `classification_report.csv`

Contains the classification report for the final evaluated model, including:

- Precision
- Recall
- F1-Score
- Support
- Accuracy

The report provides separate evaluation metrics for legitimate and fraudulent transactions.

### 2. `final_model_metrics.csv`

Stores the final model evaluation metrics in CSV format.

The reported metrics are:

| Metric | Value |
|---|---:|
| AUPRC | 0.6882 |
| Precision | 0.8276 |
| Recall | 0.7579 |
| F1-Score | 0.7912 |

These values summarize the final model's performance on the evaluation dataset.

### 3. `logistic_regression_tuning.csv`

Contains the hyperparameter tuning results for the Logistic Regression model.

The file includes:

- Tested regularization parameter values (`C`)
- Solver configuration
- Class-weight settings
- Cross-validation scores
- Mean and standard deviation of test scores
- Hyperparameter rankings

These results support the process of selecting suitable Logistic Regression hyperparameters.

### 4. `model_comparison.csv`

Contains a comparison of four Machine Learning models using AUPRC, Precision, Recall, and F1-Score.

The models included are:

- Random Forest
- Linear SVM
- Decision Tree
- Gradient Boosting

The recorded results help compare model performance, particularly when detecting fraudulent transactions in an imbalanced dataset.

### 5. `model_metrics.json`

Stores the final evaluation metrics in JSON format.

This format makes the metrics convenient to load and use in other Python scripts or reporting workflows.

## 📈 Evaluation Metrics

| Metric | Purpose |
|---|---|
| AUPRC | Evaluates precision-recall performance, especially useful for imbalanced classification |
| Precision | Measures how many transactions predicted as fraudulent are actually fraudulent |
| Recall | Measures how many actual fraudulent transactions are detected |
| F1-Score | Balances precision and recall |
| Accuracy | Measures the proportion of correctly classified transactions |
