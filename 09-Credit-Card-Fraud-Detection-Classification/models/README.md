# 🤖 Trained Machine Learning Models

## 📌 Overview

This directory contains the trained Machine Learning model generated by the **Credit Card Fraud Detection using Machine Learning Classification** project.

The model is used to predict whether a credit card transaction is legitimate or fraudulent based on transaction features.

## 📂 Files Description

### `credit_card_fraud_model.pkl`

This file stores the trained Machine Learning model selected by the project workflow after model training and hyperparameter tuning.

The model is serialized using **Joblib** and saved with a `.pkl` file extension.

It can be loaded later to make predictions without retraining the model.

The saved file may also contain the selected decision threshold used to classify transactions, depending on the model-saving implementation.

## 🎯 Model Purpose

The trained model predicts whether a credit card transaction belongs to one of two classes:

| **Class** | **Description** |
|---|---|
| `0` | Legitimate Transaction |
| `1` | Fraudulent Transaction |

## 💾 Model Loading

The saved model can be loaded using Joblib.

```python
import joblib

saved_data = joblib.load(
    "models/credit_card_fraud_model.pkl"
)

model = saved_data["model"]
threshold = saved_data["threshold"]

print("Model loaded successfully!")
print("Decision threshold:", threshold)
```

**Note:** This loading example assumes the model was saved as a dictionary containing `"model"` and `"threshold"` keys.

## ⚠️ Important Note

The model is intended for educational and research purposes. Predictions should be evaluated carefully before considering any real-world financial application.
