# 🤖 Models — Credit Card Fraud Detection

## 📌 Overview

This folder stores the trained Machine Learning model used in the **Credit Card Fraud Detection using Machine Learning Classification** project.

The trained model is used to classify credit card transactions as legitimate or potentially fraudulent based on transaction features.

## 🎯 Purpose

The `models/` folder is intended to store:

- Trained Machine Learning models.
- The selected model and its decision threshold.
- Serialized model files for reuse without retraining.

## 📁 Folder Structure

```text
models/
├── README.md
└── credit_card_fraud_model.pkl
```

## 💾 Model File

| Property | Description |
|---|---|
| File Name | `credit_card_fraud_model.pkl` |
| File Format | Pickle (`.pkl`) |
| Serialization Library | Joblib |
| Purpose | Save and reload the trained fraud detection model |
| Model Contents | Trained model and decision threshold, if saved by the training script |

## ⚙️ Loading the Saved Model

The saved model can be loaded using Joblib.

```python
import joblib

saved_data = joblib.load(
    "models/credit_card_fraud_model.pkl"
)

model = saved_data["model"]
threshold = saved_data["threshold"]

print("Model loaded successfully!")
print("Decision threshold:", threshold)
```

**Note:** This example assumes the model was saved as a dictionary containing the keys `"model"` and `"threshold"`. If your saved file uses a different structure, adjust the loading code accordingly.

## 🔍 Model Usage

The loaded model can be used to generate predictions for new transactions after applying the same preprocessing steps used during training.

Model performance should be evaluated using appropriate fraud detection metrics, including Precision, Recall, F1-Score, and Average Precision.

## ⚠️ Important Notes

- The model file is generated by the training script.
- Do not manually modify the serialized model file.
- Pickle-based files can execute malicious code when loaded. Only load model files from trusted sources.
- The saved model is intended for educational and experimental use, not direct production deployment.
