# Iris Classification

## 📌 Overview

This case study focuses on the classification of Iris flower species using Machine Learning.

The Iris dataset contains measurements of different parts of Iris flowers. The objective of this case study is to analyze the dataset and classify the flower species using Machine Learning classification algorithms.

This case study was implemented as part of my Python with Machine Learning training.

---

## 🎯 Objective

The main objective of this case study is to:

- Understand the Iris dataset.
- Analyze the dataset and its features.
- Check and preprocess the data.
- Encode the target variable.
- Divide the dataset into training and testing sets.
- Build Machine Learning classification models.
- Compare the performance of different models.
- Evaluate the models using classification metrics and confusion matrices.

---

## 📊 Dataset

The Iris dataset contains measurements of Iris flowers and their corresponding species.

### Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### Target

The target variable is the Iris flower species.

The three classes are:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

---

## 🤖 Machine Learning Algorithms

The following classification algorithms are used in this case study:

1. K-Nearest Neighbors (KNN)
2. Decision Tree Classifier
