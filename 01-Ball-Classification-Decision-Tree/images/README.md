# Images

This folder has the output screenshots of the Ball Classification case study.

## Files
- `output.png`: terminal output of `src/01_BALL_CLASSIFICATION.py`

## What the screenshot shows
- Case study heading
- Model accuracy on test data
- Predictions for two new balls
- Completion message

## How to create it again
Run from the case study folder (the one with requirements.txt):

    python src/01_BALL_CLASSIFICATION.py

Then take a screenshot of the terminal output and save it as `output.png` in this folder.
