# 📈 Images — Breast Cancer Detection Using Ensemble Learning

## 📌 Overview

This directory contains the visualizations generated by the Breast Cancer Detection Using Ensemble Learning project.

## 📁 Files

| File Name | Description |
|---|---|
| `model_comparison.png` | Compares accuracy, malignant recall, and malignant F1-score across 10 models using 5-fold cross-validation. |
| `confusion_matrix.png` | Displays the actual and predicted classifications of the selected Hard Voting model on the test dataset. |
| `feature_importance.png` | Shows the top 10 important features identified by a Random Forest classifier. |

## 🎯 Purpose

These visualizations help understand model performance, classification errors, and the features that contribute most to predictions.

## ⚙️ Generation

The images are generated automatically when `src/main.py` executes successfully.

## ⚠️ Note

These visualizations are intended for educational and machine learning analysis only, not clinical diagnosis.
