# 📊 Dataset

## Overview

This folder contains the dataset used for the Breast Cancer Detection Using Ensemble Learning project.

## Dataset File

| File | Description |
|---|---|
| `breast_cancer.csv` | Contains breast cancer measurements and target labels used for classification. |

## Dataset Information

- **Total Records:** 569
- **Input Features:** 30
- **Target Column:** `target`
- **Target Labels:** `0 = Malignant`, `1 = Benign`

## Usage

The dataset is loaded using Pandas and used to train, validate, and evaluate machine learning classification models.

**Note:** This dataset is intended for educational and research purposes only, not for clinical diagnosis.
