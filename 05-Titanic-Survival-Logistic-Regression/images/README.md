# Images

This folder contains the output images generated by the Titanic Survival Prediction case study using Logistic Regression.

## Files

| **File** | **Description** |
|---|---|
| survival_count.png | Bar chart showing the number of passengers who survived and did not survive |
| age_distribution.png | Histogram showing the age distribution of Titanic passengers with a density curve |
| confusion_matrix.png | Confusion matrix of the Logistic Regression model on the test data |

## How the images are created

All three images are created automatically when you run the code.

Run from the case study folder (the one with `requirements.txt`):

```bash
python src/main.py
```

The images are saved automatically in the `images/` folder.

## Results shown

- **Test accuracy:** 80.45%
- **Baseline accuracy:** 61.45%
- **Training samples:** 712
- **Testing samples:** 179
- **Correctly classified non-survivors:** 98
- **Correctly classified survivors:** 46
- **Incorrectly classified non-survivors as survivors:** 12
- **Incorrectly classified survivors as non-survivors:** 23

The confusion matrix and classification report help evaluate the model's performance on the test dataset.
