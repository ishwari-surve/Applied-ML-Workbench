# 📊 Visualizations — California Housing Price Prediction

## 🏡 Overview

This folder contains the visualizations generated by the **California Housing Price Prediction Using Ensemble Learning** project.

These graphs help analyze model performance, compare actual and predicted house values, understand feature importance, and visualize the geographical distribution of California housing prices.

## 📈 Visualizations Included

### 1. 📉 Model Comparison

**File:** `model_comparison.png`

Compares the six regression models using 5-fold cross-validation R² scores and RMSE values. It helps identify the best-performing ensemble model.

### 2. 🎯 Actual vs. Predicted Prices

**File:** `actual_vs_predicted.png`

Compares actual house values with predicted values from the selected model. Points closer to the perfect-prediction line indicate more accurate predictions.

### 3. 🌳 Feature Importance

**File:** `feature_importance.png`

Displays the relative importance of the input features in the Random Forest Regressor. It helps identify which features contribute most to the model's predictions.

### 4. 🗺️ California Housing Price Map

**File:** `price_map.png`

Visualizes housing data geographically using latitude and longitude. The point colors represent the median house values in different areas of California.

## 🛠️ Technologies Used

- Python
- Matplotlib
- Pandas
- NumPy
- Scikit-learn

## 🎯 Purpose

These visualizations make the Machine Learning results easier to understand and help communicate model performance and dataset patterns clearly.
