# 📊 Dataset – California Housing Price Prediction

This folder contains the dataset used for the **California Housing Price Prediction Using Machine Learning Regression** case study.

## 📁 Dataset File

- **File Name:** `california_housing.csv`
- **Dataset Size:** 20,640 samples
- **Input Features:** 8 numerical features
- **Target Variable:** `MedHouseVal`

## 📝 Dataset Description

The California Housing dataset contains information about housing districts in California. It is used to predict the median house value based on demographic, housing, and geographical features.

The dataset is loaded using Scikit-learn's `fetch_california_housing()` function and saved as a CSV file for further analysis and model training.

## 📌 Features Description

| Feature | Description |
|---|---|
| `MedInc` | Median income in the district |
| `HouseAge` | Median house age |
| `AveRooms` | Average number of rooms per household |
| `AveBedrms` | Average number of bedrooms per household |
| `Population` | District population |
| `AveOccup` | Average number of household members per household |
| `Latitude` | Geographic latitude |
| `Longitude` | Geographic longitude |
| `MedHouseVal` | Median house value, expressed in units of $100,000 |

## 🎯 Target Variable

The target variable is `MedHouseVal`.

It represents the median house value in a district, measured in units of **$100,000**. The regression models use the eight input features to predict this value.

## ⚙️ Dataset Generation

The dataset is downloaded or retrieved through Scikit-learn when the main program runs. The program then saves it as:

```text
data/california_housing.csv
```

## ⚠️ Important Notes

- The CSV file is generated by `src/main.py`.
- The dataset is used for training, testing, cross-validation, and model evaluation.
- The target values are in units of $100,000, not individual dollars.
- The dataset contains numerical features suitable for regression algorithms.
