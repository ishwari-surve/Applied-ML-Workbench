# Project Outputs

## Overview

The `outputs/` directory contains the customer-level RFM analysis results and the command-line execution log generated by the **Olist E-Commerce Analytics & Delivery Delay Prediction** project.

These files help document customer segmentation results and verify the execution of the complete data analytics and machine learning pipeline.

## Directory Structure

```text
outputs/
├── README.md
├── cmd_output.txt
├── rfm_customer_segments.csv
└── rfm_segment_summary.csv
```

## Files Description

### 1. `cmd_output.txt`

Contains the command-line execution log generated when running the project's main Python script.

The log documents the major stages of the pipeline, including:

- Loading and inspecting all nine Olist datasets.
- Checking missing values, duplicate records, and relationships between datasets.
- Cleaning and merging the datasets.
- Feature engineering and exploratory data analysis (EDA).
- Customer segmentation using Recency, Frequency, and Monetary (RFM) analysis.
- Creating the delivery-delay target variable and preparing machine learning data.
- Building and comparing five classification models.
- Selecting, training, saving, and loading the Logistic Regression model.
- Evaluating model performance and generating delivery predictions.
- Producing business insights and saving project outputs.
- Displaying the final project execution summary.

The log also records dataset statistics, model evaluation metrics, prediction summaries, generated visualizations, and output file locations.

### 2. `rfm_customer_segments.csv`

Contains customer-level RFM analysis results used to segment customers according to their purchasing behaviour.

The analysis evaluates:

- **Recency:** How recently a customer placed an order.
- **Frequency:** The number of orders placed by a customer.
- **Monetary Value:** The amount spent by a customer.

The execution log reports that **93,358 unique customers** were analysed, using `2018-08-30` as the reference date.

The identified customer segments include:

- Champions
- Loyal Customers
- Potential Loyalists
- Recent Customers
- Regular Customers
- At Risk
- Hibernating

This file can be used for customer behaviour analysis, targeted marketing, customer retention planning, and business decision-making.

### 3. `rfm_segment_summary.csv`

Contains aggregated statistics for each RFM customer segment.

The summary includes:

- Number of customers in each segment.
- Average recency in days.
- Average number of orders.
- Average customer spending.
- Total spending by segment.

These statistics help compare customer groups, identify valuable customers, and understand opportunities for customer engagement and retention.

## How These Files Are Generated

The RFM CSV files are generated during the customer segmentation stage of the project. The command-line log can be captured or saved when executing the main Python script.

From the project root directory, run:

```bash
python src/main.py
```

If you are already inside the `src/` directory, run:

```bash
python main.py
```

The required raw datasets must be available in the expected project data directory, and the necessary Python dependencies must be installed.

## Important Notes

- The CSV files contain generated analysis results; they are not raw source datasets.
- `cmd_output.txt` records the execution output from a particular run. Its results may change if the data, code, dependencies, or model configuration changes.
- The command-line log contains local Windows file paths from the development environment. These paths will differ on another computer.
- The RFM results support customer analytics and business interpretation; they do not represent machine learning model evaluation results. Those files are maintained separately in the `results/` directory.

## Project Purpose

This directory supports the project's broader objective of combining e-commerce data analysis, customer segmentation, delivery-delay prediction, and business insights to understand purchasing behaviour and improve delivery operations.
