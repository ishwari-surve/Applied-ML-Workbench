# 📁 Results — Olist E-Commerce Analytics & Delivery Delay Prediction

## 📌 Overview

The `results` directory contains the analytical outputs generated by the **Olist E-Commerce Analytics and Delivery Delay Prediction** project.

These outputs include customer-level RFM segmentation, customer segment summaries, machine learning model comparisons, delivery predictions, model evaluation metrics, and business insights.

The files support exploratory analysis, customer segmentation, model evaluation, business interpretation, and further reporting using Power BI.

## 📂 Directory Structure

```text
results/
├── README.md
├── rfm_customer_segments.csv
├── rfm_segment_summary.csv
├── model_comparison.csv
├── delivery_predictions.csv
├── model_evaluation_metrics.csv
└── business_insights.json
```

## 📊 Output Files

### 1. Customer-Level RFM Segmentation

**File:** `rfm_customer_segments.csv`

**Description:**

Contains customer-level Recency, Frequency, and Monetary (RFM) analysis results.

**Columns:**

| Column | Description |
|---|---|
| `customer_unique_id` | Unique customer identifier |
| `recency` | Recency value in days |
| `frequency` | Number of orders used in the analysis |
| `monetary` | Monetary value associated with the customer |
| `R_score` | Recency score |
| `F_score` | Frequency score |
| `M_score` | Monetary score |
| `RFM_score` | Combined RFM score |
| `customer_segment` | Assigned customer segment |

**Purpose:**
- Understand customer purchasing behavior.
- Identify customer segments based on activity and spending.
- Support customer retention and engagement strategies.

### 2. RFM Customer Segment Summary

**File:** `rfm_segment_summary.csv`

**Description:**

Contains aggregated statistics for the customer segments identified during RFM analysis.

**Columns:**

| Column | Description |
|---|---|
| `customer_segment` | Customer segment name |
| `customers` | Number of customers in the segment |
| `average_recency_days` | Average recency in days |
| `average_orders` | Average number of orders per customer |
| `average_spending` | Average monetary value per customer |
| `total_spending` | Total monetary value associated with the segment |

**Purpose:**
- Compare the sizes of customer segments.
- Analyze differences in customer activity and spending.
- Identify opportunities for targeted marketing and retention.

### 3. Machine Learning Model Comparison

**File:** `model_comparison.csv`

**Description:**

Contains the cross-validation results used to compare the classification models developed for delivery-delay prediction.

**Columns:**

| Column | Description |
|---|---|
| `Model` | Name of the classification model |
| `Average Precision` | Average Precision score from cross-validation |
| `Recall` | Recall score from cross-validation |
| `F1-Score` | F1-score from cross-validation |

**Purpose:**
- Compare model performance using consistent evaluation metrics.
- Support the selection of a candidate model.
- Document the model comparison process.

### 4. Delivery Prediction Results

**File:** `delivery_predictions.csv`

**Description:**

Contains the actual delivery outcomes and model-generated predictions for the held-out test dataset.

**Columns:**

| Column | Description |
|---|---|
| `order_index` | DataFrame index associated with the test record |
| `Actual_Status` | Actual binary target value |
| `Predicted_Status` | Predicted binary target value |
| `Late_Probability` | Model-estimated probability of late delivery |
| `Actual_Delivery_Status` | Actual outcome as On-Time or Late |
| `Predicted_Delivery_Status` | Predicted outcome as On-Time or Late |
| `Risk_Level` | Assigned risk category: Low, Medium, or High |

**Purpose:**
- Compare actual and predicted delivery outcomes.
- Examine late-delivery probabilities.
- Identify records flagged as high risk.
- Support further analysis and Power BI reporting.

**Note:** `order_index` is a DataFrame index, not a verified Olist order ID.

### 5. Model Evaluation Metrics

**File:** `model_evaluation_metrics.csv`

**Description:**

Contains the final test-set evaluation metrics for the selected model.

**Columns:**

| Column | Description |
|---|---|
| `Metric` | Evaluation metric name |
| `Score` | Corresponding metric value |

The output includes Average Precision, Precision, Recall, and F1-score.

**Purpose:**
- Summarize the selected model's performance on unseen test data.
- Support transparent evaluation and reporting.
- Track performance when the model is updated.

### 6. Business Insights and Recommendations

**File:** `business_insights.json`

**Description:**

Stores structured delivery statistics, prediction summaries, evaluation metrics, and business recommendations in JSON format.

**Main fields:**

| Field | Description |
|---|---|
| `total_orders` | Number of test orders analyzed |
| `actual_late_orders` | Number of actually late orders |
| `actual_ontime_orders` | Number of actually on-time orders |
| `actual_late_percentage` | Actual late-delivery rate |
| `predicted_late_orders` | Number of orders predicted late |
| `predicted_ontime_orders` | Number of orders predicted on time |
| `predicted_late_percentage` | Percentage of orders predicted late |
| `high_risk_orders` | Number of orders classified as high risk |
| `high_risk_percentage` | Percentage of orders classified as high risk |
| `average_precision` | Test-set Average Precision |
| `precision` | Test-set Precision |
| `recall` | Test-set Recall |
| `f1_score` | Test-set F1-score |
| `recommendations` | List of generated business recommendations |

**Purpose:**
- Summarize delivery performance and prediction results.
- Provide structured information for reports and dashboards.
- Communicate potential operational improvements.

## 🔄 Output Generation Workflow

The results are generated through the project's Python pipeline:

1. Prepare and analyze the source datasets.
2. Calculate customer-level RFM metrics and segments.
3. Aggregate customer segment statistics.
4. Build and compare classification models.
5. Select and train a model.
6. Evaluate predictions on the held-out test dataset.
7. Generate delivery predictions and business insights.
8. Export results to CSV and JSON files.

## 📝 Notes

- The RFM files and machine learning outputs serve different analytical purposes.

- Risk categories depend on the probability thresholds configured in the source code.
- Monetary values follow the definitions implemented in the RFM analysis.
- The CSV and JSON files can be regenerated by running the project pipeline.
