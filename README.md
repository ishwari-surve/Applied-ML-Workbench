# 🤖 Applied Machine Learning Workbench

A collection of hands-on machine learning case studies built in Python. Each case study follows an industry-style structure: data loading, cleaning, training, evaluation and prediction, with its own source code, requirements and README.

## 📚 Case Studies

| No. | Case Study | Type | Algorithm | Result |
|-----|------------|------|-----------|--------|
| 01 | [Ball Classification](01-Ball-Classification-Decision-Tree) | Classification | Decision Tree | 100% accuracy (2 test samples) |
| 02 | [Iris Classification](02-Iris-Classification) | Classification | KNN, Decision Tree | KNN 100%, Decision Tree 93.33% |
| 03 | [Advertising Sales Prediction](03-Advertising-Sales-Linear-Regression) | Regression | Multiple Linear Regression | R² 0.8994, RMSE 1.78 |

More case studies will be added.

## ▶️ How to Run a Case Study
1. Clone the repository:
```bash
   git clone https://github.com/ishwari-surve/Applied-ML-Workbench.git
```
2. Open a case study folder:
```bash
   cd Applied-ML-Workbench/03-Advertising-Sales-Linear-Regression
```
3. Install the requirements:
```bash
   pip install -r requirements.txt
```
4. Run the code:
```bash
   python src/main.py
```

Each case study README has the details, results and output screenshots.
